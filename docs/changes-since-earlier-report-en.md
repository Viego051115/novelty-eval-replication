# Additions since the earlier report

Compared with the earlier 37-configuration stage, we completed three Human-Only plan-format experiments (P3, P4 and P5), bringing the source matrix to 40 configurations. Following the authors' code, we derived 22 no-aggregation conditions from the saved votes; 18 add distinct conditions after deduplication, giving 58 covered conditions in total. We also completed 120 paired BCa comparisons and updated the corresponding figures. Retrieval, matched reasoning-budget comparisons and dedicated evaluators remain unfinished. This document refresh adds no new model calls or experimental conditions.

The updated [two-page English report](DeepSeek_Progress_Brief_EN.pdf) includes a table comparing the newly completed Human-Only plan results with the previously available Human+Generated results.
